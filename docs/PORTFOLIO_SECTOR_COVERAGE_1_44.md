# Vertex — couverture sectorielle portefeuille

Le contexte portefeuille expose `sector_mix` et `sector_coverage` depuis le référentiel sectoriel existant. Les secteurs sont agrégés uniquement pour les symboles effectivement connus de ce référentiel.

Les symboles sans classification restent dans `unclassified_symbols` et leur valeur reste quantifiée séparément. Vertex ne leur attribue jamais de secteur par défaut.

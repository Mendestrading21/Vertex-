# Vertex — couverture de données de l’environnement options

L’environnement options expose `data_coverage` avec les dimensions connues, le taux de couverture et les dimensions inconnues parmi volatilité, IV rank, qualité, liquidité et calendrier.

Les dimensions inconnues sont exclues de la moyenne existante, mais restent listées. Elles ne deviennent jamais un score nul, favorable ou une recommandation implicite.

# Vertex — contexte fondamental Skyler

Le contexte `fundamentals` de Skyler lit uniquement `scan_state.fundamentals`. Il expose les valeurs par titre réellement collectées, les médianes sectorielles disponibles et la liste des champs absents.

Les fondamentaux potentiellement différés restent étiquetés comme tels. Aucun champ manquant n’est remplacé, et le contexte est strictement descriptif, en lecture seule.

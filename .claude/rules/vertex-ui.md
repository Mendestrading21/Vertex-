# Interface Black Glass

- Direction unique : Black Glass — Signal Light, Geist/Geist Mono, français.
- Tokens `--vx-*`, composants partagés, une lumière dominante par carte ; zéro
  glow permanent, arc-en-ciel, esthétique casino ou mini-thème local.
- Vert positif, rouge risque, ambre prudence, violet options, cyan focus rare ;
  le sens ne dépend jamais de la couleur seule.
- L'UI ne recalcule ni prix, score, Greek, R:R, gate, probabilité ou verdict.
- Chaque graphique expose question, unité, source, période, fraîcheur, état et
  fallback tabulaire.
- États loading/empty/partial/stale/delayed/offline/demo/error, clavier, focus,
  zoom 200 %, reduced motion et 1600/1024/390 obligatoires.
- Préserver routes, IDs, événements et clés jusqu'à migration cartographiée.
- Apostrophes françaises dans une chaîne JS : échapper ou utiliser une chaîne
  sûre. Changement de shell cacheable : vérifier puis bumper le service worker.
